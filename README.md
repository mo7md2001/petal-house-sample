# Petal House (sample project)

A demo e-commerce storefront built by Mohamed Essam to show layout and ordering flow: header, product grid, cart, about, shipping and returns, reviews, FAQ, newsletter, contact, chat widget and footer. Everything is placeholder content: not a real store, no real products, orders, contact details or customer reviews. Product photos are AI-generated. Arabic (RTL) by default with an English toggle. Single file (index.html), no dependencies.
