# Petal House (sample project)

A demo e-commerce storefront built by Mohamed Essam to show layout and ordering flow: category tabs, product pages with options and add-on suggestions, cart, about, shipping and returns, reviews, FAQ, newsletter, contact, chat widget and footer. Everything is placeholder content: not a real store, no real products, orders, contact details or customer reviews. Product photos are AI-generated. Arabic (RTL) by default with an English toggle. Plain HTML/JS, no dependencies. Each product has its own page (product-1.html to product-8.html).
